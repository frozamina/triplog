途迹 TripLog

把一次长途出行拆成「段」——每段走了多久、花了多少，段与段之间的换乘等待也单独成条。 于是「这趟为什么这么累」终于有了答案：22% 的时间，你在站着等。

规则 · Rules

圆角卡片 16–20 · 内元素 8–12 · 胶囊 999。三级封顶。
阴影只有两级：静止 0 1px 2px，浮起 0 8px 24px。绝不叠加三层。
强调色赤陶只给「花费」与「等待」。稀缺，才有力量。
动效位移缩放用 spring，尺寸变化用 emphasized，纯淡入用 decelerate。
留白8pt 网格。屏内左右边距 22px，卡片内 15px，段落之间 9px。
数据视图洞察与对比走表格逻辑：指标在左、读数右对齐、共用网格线。但配色不换——仍是同一套纸白与墨绿。
底线点击区 ≥ 44px；等待段同时用空心点 + 斜纹 + 文案标识，不单靠颜色。
